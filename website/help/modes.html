Strict, Learn, and Normal

The mode changes how aggressively Threatwatch intervenes. It does not change whether a site is lawful, official, trustworthy, or free of malware.

Strict

Strict is the default choice for a site you expect to behave aggressively. It blocks unexpected top-level exits and runs Threatwatch's main page-level security controls.

Learn

Learn behaves like Strict for containment. It adds a decision marker to unexpected navigation records so you can inspect what a site tried to do before deciding whether any destination belongs on an allowlist.

Normal

Normal is observation-first. It records unexpected web exits but does not install the Strict-only protocol, download, clipboard, ClickFix, and overlay guards.

Do not switch to Normal merely to make a broken site work. First inspect what was blocked. Reducing protection can restore a player and restore the malicious behavior at the same time.

Profile flags

Each profile can disable some defenses inside a mode. A profile flag can narrow the mode policy. It does not turn a Strict-only defense on in Normal mode.
