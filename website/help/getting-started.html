Getting started with Threatwatch

Threatwatch 0.4.0 is currently a developer build. You load it directly from the repository rather than installing it from the Chrome Web Store.

Requirements

  • Chrome 145 or newer.
  • A local copy of the Threatwatch repository.
  • Developer mode enabled at chrome://extensions.

Install the extension

  1. Download or clone the Threatwatch repository.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Select Load unpacked.
  5. Choose the repository root, the folder containing manifest.json.
  6. Pin Threatwatch from Chrome's extensions menu.
After pulling a new version, return to chrome://extensions and select Reload on the Threatwatch card.

Add a site to your watchlist

  1. Visit the site you want to monitor.
  2. Select the Threatwatch toolbar icon.
  3. Choose a watch mode. Strict is the safest default for a site you do not trust.
  4. Select Watch this site.

You can manage many profiles from Open watchlist. The settings page supports search, mode filters, activity sorting, and compact rows.

Confirm protection health

Open the watchlist and check Protection status. A healthy status means Threatwatch successfully reconciled the active page guards, dynamic network rules, and browser content settings it manages.

Healthy does not mean the website is safe. It means Threatwatch's configured protection layers loaded successfully.

Start with Learn when you are diagnosing a new site

Learn mode blocks with the same core containment behavior as Strict and marks unexpected navigation decisions for later review. Use it when you want to see what a site keeps trying to reach before making any allowlist decision.

What to do after a catch

Open the toolbar popup or watchlist. Look at the event type, action, target, and protection layer. Do not approve a destination just because the player stops working. A blocked destination can be advertising, tracking, a player dependency, or something hostile.
