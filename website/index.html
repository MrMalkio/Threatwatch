The premise is simple: people will visit risky sites with or without a safety tool. Threatwatch is built to reduce the damage, show what the browser tried to do, and give the user tighter control over what gets through.
What it watches

Protection built around the tricks these sites actually use

Threatwatch combines browser network rules, page-level interception, navigation correlation, permission hardening, and a local event log.

↗

Redirect and popunder containment

Unexpected top-level exits and spawned tabs can be blocked before they carry you into a rotating ad or scam destination.

↓

Download containment

Known risky URLs and response headers are blocked early. Downloads that still reach Chrome are paused, cancelled, and logged.

⌘

ClickFix and clipboard defense

Threatwatch warns on fake verification patterns and can block suspicious command payloads written to the clipboard.

▧

Overlay cleanup

Likely transparent click-capture overlays can lose pointer access rather than stealing the next click.

◎

Permission hardening

Protected domains can be denied notifications, popups, and automatic multi-download permission through Chrome settings.

●

Local catch log

Threatwatch keeps a local record of interventions using sanitized URLs, so you can see what it stopped without preserving secret query data.

Three watch modes

Choose how hard Threatwatch should intervene

S

Strict

Blocks unexpected external navigation and runs the full protocol, download, clipboard, ClickFix, and overlay defenses.

L

Learn

Uses Strict containment and marks navigation decisions for review, useful when you are figuring out what a new site actually needs.

N

Normal

Logs unexpected web exits but does not run the Strict-only page defenses. Use it when you want observation with less intervention.

What it is not

Threatwatch reduces browser risk. It does not make a risky site safe.

  • It is not antivirus or endpoint security.
  • It does not guarantee that every malicious action will be detected or stopped.
  • It does not determine whether third-party content is lawful, licensed, official, or authorized.
  • It is not a streaming provider, media host, or public directory of replacement streaming domains.
  • A site working well does not mean the site has lower observed risk.

Coming later

Community-sourced domain reputation

Threatwatch is being designed so users can contribute evidence about whether a domain works, how the experience felt, what threat activity was observed, and how strong the evidence is. Those are separate measurements. A working player never becomes a green safety badge.
