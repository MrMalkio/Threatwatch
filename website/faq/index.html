Frequently asked questions

Questions worth asking before you trust a browser security extension

Short answers first. Threatwatch makes strong interventions, so the product should be clear about what it sees, what it stores, and where its authority stops.

Does Threatwatch make a streaming site safe?

No. Threatwatch reduces selected browser risks. A site can still be deceptive, compromised, unlawful, invasive, or dangerous in ways the extension does not detect.

Is Threatwatch an antivirus replacement?

No. Keep endpoint security, browser updates, operating-system protections, and normal judgment. Threatwatch operates inside Chrome and cannot see or control everything your security software can.

Why can Norton still alert before or after Threatwatch?

Endpoint security can inspect traffic or file-system activity outside Chrome's extension layer. Threatwatch blocks common attempts early and cancels late download items, but it cannot guarantee which product observes a race first.

What data leaves my browser today?

Threatwatch 0.4.0 has no Threatwatch telemetry backend. Profile settings, threat events, runtime state, and watchlist preferences stay in browser storage. The public website is static and has no Threatwatch analytics or advertising scripts.

Does Threatwatch save every page I visit?

No. It processes active tab and navigation information to provide its browser-facing protection. It does not upload a chronological browsing history. Local threat records use sanitized URLs with credentials, query strings, and fragments removed.

Why does the extension request broad host access?

Threatwatch needs to observe and intervene on the sites a user chooses to protect, including frames and destinations involved in hostile behavior. The project should continue reducing permissions when Chrome exposes narrower ways to deliver the same feature.

What is Strict mode?

Strict blocks unexpected external navigation and enables the full set of page-level protocol, download, clipboard, ClickFix, and overlay protections supported by the current build.

What is Learn mode?

Learn uses Strict containment and marks unexpected navigation decisions for review. It is useful when you are studying a new site's behavior.

What is Normal mode?

Normal logs unexpected web exits but leaves Strict-only page defenses off. It is less restrictive and should not be used as a quick fix for a site that breaks under Strict.

Does Threatwatch block every download?

Under Strict and Learn, the intent is download lockdown for the protected context. Threatwatch intercepts several page APIs, blocks selected risky network patterns, and cancels download items that still reach Chrome. Browser races and unsupported techniques can still exist.

Can Threatwatch tell me whether a site is official or legal?

No. Threatwatch does not verify licensing, ownership, copyright authorization, or legal status. The user remains responsible for what they access and how they use third-party sites.

Why are there default site profiles?

The developer build includes a small set of example protected domains based on the project's original testing context. A profile is a protection configuration, not an endorsement or safety certification.

Can I add my own site?

Yes. Use the toolbar popup on the site or the watchlist settings page. Strict is the safer default for an unfamiliar domain.

What should I do if Threatwatch blocks a player dependency?

Inspect the event and verify the destination independently. Use the narrowest exact-domain allowlist entry you can justify. Do not disable the whole profile as the first response.

Will Threatwatch have community ratings?

That is on the roadmap. The proposed model keeps four measurements separate: availability, user experience, observed threat activity, and evidence confidence. A domain that works can still carry a high observed-risk rating.

Will community features upload my browsing history?

The proposed design is local-first and opt-in. It calls for coarse evidence receipts rather than full URLs, titles, searches, or chronological click logs. Those features are not active in 0.4.0 and would require updated disclosures before launch.

Will Threatwatch become a directory of working streaming sites?

The current product boundary says no. Threatwatch can assess a hostname a user already visits or submits, but the public product is not intended to rank and link replacement streaming domains.

Is Threatwatch free?

The core local protection is intended to remain free and open source. Future paid features, if any, are planned around recurring server cost and convenience such as sync, longer cloud history, administration, alerts, or API access.

Can I use Threatwatch to bypass DRM, paywalls, or site controls?

No. The project's purpose is browser safety and harm reduction, not bypassing access controls or helping users infringe third-party rights.

Where do I report a security issue in Threatwatch itself?

Use the repository's Security area for sensitive vulnerabilities when private reporting is available. Use public issues for non-sensitive bugs.
