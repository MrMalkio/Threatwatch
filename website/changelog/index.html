Public website and help center

  • Validated the release with 31 repository checks.

September 5, 2026

0.3.0 · Preemptive download containment

  • Added MAIN-world download guards at document_start.
  • Added pre-request DNR rules for risky filenames and response-header blocking for attachment and executable MIME patterns.
  • Preserved source context across spawned tabs.
  • Added immediate Chrome download pause/cancel fallback and residual-file cleanup attempts.
  • Validated the release with 25 repository checks.

August 23, 2026

0.2.0 · Audit remediation

  • Separated Normal, Strict, and Learn policy behavior.
  • Fixed persistence-boundary URL sanitization.
  • Fixed blank-popup and non-web protocol handling.
